# 로컬메모장

브라우저에서만 동작하는 로컬 Markdown 메모장입니다.  
[File System Access API](https://developer.mozilla.org/en-US/docs/Web/API/File_System_API)로 PC(또는 Google Drive 동기화) 폴더의 `.md` 파일을 직접 읽고 쓰며, **서버 업로드 없이** 파일이 그 자리에 저장됩니다.

> Chrome 또는 Edge가 필요합니다. (Firefox·Safari는 File System Access API 미지원)

---

## 이런 분에게 맞습니다

- Google Drive 등에 둔 Markdown을 **크롬에서 바로 편집**하고 싶을 때
- 설치·로그인·클라우드 에디터 없이 **로컬 파일만** 다루고 싶을 때
- 폴더 트리 + 미리보기형 편집 + 목차(TOC)가 한 화면에 필요할 때

---

## 시작하기

### 1. 앱 열기

빌드 과정은 없습니다. 아래 중 하나로 엽니다.

1. `index.html`을 Chrome / Edge로 연다  
2. 또는 로컬 정적 서버로 서빙한다 (예: Live Server, `npx serve`)

**주의:** `drive.google.com` 미리보기·공유 링크로 HTML을 열면 스크립트가 정상 동작하지 않습니다.  
Google Drive for Desktop로 동기화된 **로컬 경로**의 `index.html`을 여세요.

### 2. 메모 폴더 연결 (최초 1회)

1. 화면 안내에 따라 **연결**을 누릅니다.
2. `.md` 파일이 들어 있는 폴더(예: `memos`)를 선택하고 읽기/쓰기 권한을 허용합니다.
3. 선택한 폴더 핸들은 브라우저 IndexedDB에 저장되어, 다음 방문 때 목록을 바로 불러옵니다.

권한이 만료되었거나 목록이 비면 왼쪽 하단 **⟳(재연결)** 으로 같은 폴더를 다시 선택하세요.

### 3. 파일 열고 편집

1. 왼쪽 트리에서 `.md` 파일을 클릭합니다.
2. 가운데 에디터에서 바로 수정합니다. (렌더된 Markdown을 보면서 편집)
3. 입력을 잠시 멈추면 자동 저장됩니다. 왼쪽 상단 상태로 확인합니다.
   - `수정됨` → `저장 중…` → `저장됨`

별도 저장 버튼은 없습니다. 디스크의 원본 `.md`가 갱신됩니다.

## 화면 구성

| 영역 | 역할 |
|------|------|
| 왼쪽 | 폴더·파일 트리, 검색, 새 파일/폴더, 재연결 |
| 가운데 | Markdown 편집기 (`contenteditable`) |
| 오른쪽 | 현재 문서 헤딩 목차(TOC) — 클릭 시 해당 위치로 이동 |

---

## 주요 기능

### 파일·폴더

- **검색**: 왼쪽 검색바에 이름(경로) 일부를 입력하면 트리가 필터됩니다.
- **새 파일 / 새 폴더**: 왼쪽 하단 버튼. 폴더 행의 문서 아이콘으로 그 폴더 안에 md를 만들 수도 있습니다.
- **이름 변경·삭제**: 각 행의 연필·휴지통 아이콘.
- **폴더 접기/펼치기**: 폴더 행 클릭.

### 편집·저장

- 타이핑을 멈추면 약 0.4초 뒤 자동 저장.
- 한글 IME 조합이 끝날 때, 에디터 포커스를 잃을 때, 탭을 숨길 때도 대기 중인 내용이 저장됩니다.
- 오른쪽 TOC는 문서의 `h1`~`h4`를 기준으로 자동 갱신됩니다.

### Markdown 확장

- 하이라이트: `==텍스트==` 또는 `==색:텍스트==` (예: `==red:중요==`, `==#f59e0b:주의==`)
- 일반 링크는 새 탭으로 열립니다.

## Google Drive와 함께 쓰기

1. Drive for Desktop로 `notebook`(또는 메모 폴더)을 PC에 동기화합니다.
2. 동기화된 `index.html`을 Chrome에서 엽니다.
3. 연결 시 **메모가 들어 있는 로컬 폴더**(예: `…\notebook\memos`)를 선택합니다.
4. 편집 내용은 로컬 파일에 쓰이고, Drive 동기화로 다른 기기·공유에도 반영됩니다.

클라우드 전용(온라인만) 파일이면 목록이 비거나 읽기 실패할 수 있습니다. 자주 쓰는 폴더는 **오프라인 사용 가능**으로 두는 것을 권장합니다.

---

## 요구 사항·한계

- **브라우저:** Chrome, Edge (최신 권장)
- **의존성:** `marked.min.js` 하나. 설치·빌드 없음.
- 서버에 메모를 올리지 않습니다. 연결한 폴더 밖의 파일에는 접근하지 않습니다.
- 이 저장소(또는 GitHub)에는 **앱 소스만** 두는 것을 권장합니다. `memos/` 같은 실제 노트·비밀번호는 커밋하지 마세요.
